# Hand-Implementing Sutskever's Thirty Papers

- Implement and retrieve from your own memory, without any AI or autocomplete tools.
- Use only NumPy and SciPy.
- Overcome your fundamental misjudgement: mistaking fluency for learning, and introduce breaks; you overestimate what you can retrieve five minutes later.
- On the road to learning how to learn and to general intelligence, every other path of premature application or vertical-domain monetization is a detour.
- Assert, test, and guess first.
- Read the classics; do not waste time picking up new tools and frameworks.
- Seek inward: you already have a neural network refined over millions of years.
